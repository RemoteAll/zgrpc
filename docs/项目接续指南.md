## 1. 项目速览

- 名称：`zgrpc`；目录：`E:\Code\Zig\zgrpc`；远端 `origin/main`（https://github.com/RemoteAll/zgrpc）。
- 定位：**纯 Zig、零依赖**的 gRPC / HTTP/2 协议栈（Zig 0.17.1+）；不依赖 zzig。
- 分层：`hpack`（头部压缩）→ `h2`（h2c 服务端，多路复用）→ `grpc`（消息分帧/状态/路由）。
- 仓库约定：`src/zgrpc.zig` 是模块根；测试就近放在各 `src/*.zig` 内。

## 2. 常用命令

```powershell
zig build            # 构建（含示例 exe）
zig build test       # 全部单测（41 个（另加生成代码 4 个），含 h2 / gRPC 端到端 / 客户端 / bidi / gRPC-Web）
zig build echo-server
zig build echo-client
```

一键回归：`powershell -NoProfile -ExecutionPolicy Bypass -File tools\regression.ps1`（退出码 0/1；测试下限 41）。

Rust 对拍（工具在 `tools/interop-rust`，不参与 zig build）：

```powershell
cd tools\interop-rust; cargo build --release
.\target\release\zgrpc-interop.exe server --port 18061          # Rust 服务端（测 zgrpc 客户端）
.\target\release\zgrpc-interop.exe client --port 18051          # Rust 客户端（测 zgrpc 服务端）
.\target\release\zgrpc-interop.exe client --port 18051 --web    # gRPC-Web
```
